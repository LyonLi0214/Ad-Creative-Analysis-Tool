## 1. 项目概览

搭建一个游戏素材拆解分析协作平台，支持：
- 多游戏素材分析（心动防线、黑帮等）
- 四维拆解 + 6维标签体系
- 6并发并行分析（OSS下载→ffmpeg→opencv→Mimo AI）
- NocoDB 网页协作 + 实时进度面板
- Excel 固定输入输出框架

## 5. 分析框架

### 5.1 四维拆解框架

每条素材按四个维度拆解：

| 维度 | 关注点 |
|------|--------|
| **前3秒·钩子** | 视觉冲击 / 听觉锚点 / 文案悬念 — 用什么方式抓住注意力？ |
| **核心卖点·主体** | 玩法展示 / 心理诉求 / 角色情感 — 主体展示了什么？ |
| **视听语言·包装** | 节奏设计 / 风格调性 / 文化适配 — 画面风格、BGM、节奏如何？ |
| **转化路径·CTA** | 类型 / 文案 / 位置 — 结尾如何引导转化？ |

### 5.2 6维标签体系

| 维度 | 标签数 | 标签值 |
|------|--------|--------|
| **hook_策略** | 13 | 反常识标题、教学攻略、福利展示、擦边/角色吸引、剧情/抓马、口播推荐、问题型标题、选择互动、福利激励、核心玩法展示、来电钩子、定制互动、噱头/爆点 |
| **角色元素** | 8 | 黑皮、猫耳/兽耳、Q版角色、多角色、立绘展示、真人出镜、AI虚拟人、无角色 |
| **场景元素** | 7 | 弹球/战斗、选择界面、Boss战、胜利结算、福利界面、模拟UI、直播间 |
| **制作方式** | 6 | K帧动画、真人口播、AI口播、实机录屏、图片轮播、混合 |
| **叙事模式** | 10 | 问题-解法、反差逆袭、攻略教学、角色推荐、悬念-揭秘、福利直给、选项驱动、擦边吸引、角色展示、聊天模拟 |
| **画面风格** | 6 | 二次元精致渲染、Q版可爱风、AI合成、实机录屏、实拍、混剪 |

### 5.3 拆解输出字段

| 类别 | 字段 |
|------|------|
| 拆解维度 | Hook内容、Hook类型、人物、UI元素、特效、色彩、字幕、节奏、BGM、核心卖点 |
| 6维标签 | hook_策略、角色元素、场景元素、制作方式、叙事模式、画面风格 |
| 扩展维度 | 目标受众、情绪触发、营销策略、可优化方向 |
| AI元数据 | AI置信度、标签状态、分析时间、人工批注 |

### 5.4 视频分析流程

```
OSS 下载 → ffmpeg 提取元数据（时长、分辨率、编码、FPS、音频）
         → ffmpeg 提取关键帧（I帧优先，不足则均匀采样）
         → opencv 分析关键帧（亮度、复杂度、主色调）
         → 构建 prompt（元数据 + 视觉特征 + 投放数据 + 标签库）
         → Mimo AI 四维拆解分析
         → 写 Excel + NocoDB
```

## 11. 注意事项

1. **OSS 只能在公司网络下访问** — Windows 必须在公司内网或有公司 VPN
2. **NocoDB API 列名用中文** — 过滤语法 `@("字段名",eq,"值")`
3. **Mimo API 是推理模型** — max_tokens 要设 4000+，否则输出被 reasoning 吃掉
4. **中文路径问题** — opencv 需要用 `cv2.imdecode` 代替 `cv2.imread`
5. **SingleSelect 列** — NocoDB API 不支持修改列选项，新建库时统一用 SingleLineText
6. **Nginx 代理** — 进度面板在 /，NocoDB 在 /nc/
7. **ffmpeg 路径** — 通过 `imageio_ffmpeg.get_ffmpeg_exe()` 获取，不需要单独安装
