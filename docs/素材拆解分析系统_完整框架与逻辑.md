# 素材拆解分析系统 — 完整框架与逻辑

> 权威架构文档 · 版本 v3.0 · 2026-08-05
> 覆盖：架构、管线、数据模型、标签体系、脚本清单、已知问题、规划

---

## 1. 系统定位

**游戏广告素材的 AI 拆解分析协作平台**，解决三个问题：

1. **素材太多看不过来** → 自动下载 → 识别 → 分析 → 结构化存储
2. **分析结果不可复用** → 四维拆解 + 6维标签 + 逐帧拆解 + ASR原文沉淀为知识库
3. **投放效果与素材脱节** → 素材↔效果聚合，指导变体迭代

## 3. 核心管线（正式版）

### 3.1 完整分析管线 `analyze_pipeline_full.py`

```
① Excel 素材总览 (投放数据: 花费/CTR/安装/ROI/次留, 状态=待分析)
      │
      ▼
② OSS 下载素材 → downloads/new_materials/
      │  按素材编号+日期+分辨率指纹匹配，避免同名不同版本
      ▼
③ ffmpeg 提帧 + 元数据 (时长/分辨率/FPS/音频有无)
      │
      ▼
④ 本地识别 (language 按游戏配置: ja/zh)
      │  ├─ OCR      PaddleOCR v6 small    → 字幕/UI文字
      │  ├─ ASR      faster-whisper small  → 口播转写
      │  ├─ CLIP     clip-vit-base-patch32 → 角色/场景/UI语义
      │  └─ 镜头切分 opencv_histogram      → 秒级分段
      │  每条 60~260 秒
      ▼
⑤ evidence JSON (可追溯证据: 每段 OCR/ASR/CLIP 原文+置信度)
      │
      ▼
⑥ AI 分析 (DeepSeek v4-flash, max_tokens=8000)
      │  四维拆解 + 6维标签 + 目标受众/情绪/策略/优化方向
      │  规则: 标签必须从体系选取; 文案/字幕列写入真实ASR/OCR原文
      │  每条 15~30 秒
      ▼
⑦ 写入 Excel (总结分析 + 逐帧拆解[含ASR原文])
      │
      ▼
⑧ 保存 SQLite (ai_analysis + frame_timeline)
```

### 3.2 管线原则（踩坑总结）

| 原则 | 原因 |
|------|------|
| **先识别后分析，禁止跳步** | AI 看不到视频，没有证据全靠猜 → 内容不可信 |
| **标题不作标签依据** | 素材名是人工命名，不代表画面真实内容 |
| **证据全量保留** | 每条素材的 evidence JSON 可追溯，人工可复核 |
| **游戏背景注入 prompt** | 不注入 → AI 不知道游戏是什么，标签乱选 |
| **标签必须从体系选，禁止自创** | 否则聚合统计失真 |

## 4. 本地识别模块（local_recognition/）

| 组件 | 模型 | 语言 | 产出 |
|------|------|------|------|
| OCR | PaddleOCR PP-OCRv6_small (det+rec) | 中/日/繁 | 文本+位置+置信度 |
| ASR | faster-whisper small (CPU INT8) | 按游戏 (ja/zh) | 语音转写+时间戳 |
| CLIP | openai/clip-vit-base-patch32 | 英文prompt/中文标签 | 分组语义候选+置信度 |
| 镜头切分 | opencv 直方图 | — | 秒级片段 (seg_001...) |
| CTA 检测 | OCR 文本+位置+置信度联合 | — | 转化引导有无 |
| 证据校验 | schema.py validate_evidence | — | 限制伪时间轴/无证据推断 |

**工作方式**：每个识别组件独立 worker 进程（避免 Windows DLL 冲突），产出 JSON 观察，由 recognize_asset.py 汇总为 evidence JSON。

## 6. 数据模型

### 6.1 SQLite 核心表 (data/mova_materials.sqlite3)

| 表 | 作用 | 关键字段 |
|----|------|----------|
| material_registry | 素材注册表 | material_key, material_name, game_name, normalized_name |
| game_background | 游戏背景库 | game_key, game_name, 玩法/卖点/风格/目标市场/角色 |
| ai_analysis | AI分析结果 | material_key, hook_*, 6维标签, 受众/情绪/策略, ai_confidence |
| frame_timeline | 逐帧拆解 | material_key, 时间轴, 画面内容/元素, 字幕(ASR原文), 音效, 目的, 可借鉴点 |
| aggregation_results | 聚合结果 | 游戏/维度/标签值/素材数/平均花费/ROI |
| appsflyer_daily_facts | 投放效果 | 日粒度花费/安装/事件 |
| material_appsflyer_mapping | 素材↔效果关联 | material_key ↔ campaign 映射 |
| meta_ad_daily | Meta广告数据 | 10685行/8账户/2470广告 |
| meta_sync_runs | Meta同步记录 | run_id, status, error |

### 6.2 Excel 模板（5 Sheet）

| Sheet | 角色 | 内容 |
|-------|------|------|
| 素材总览 | 输入 | 素材名称/游戏/平台/类型 + 20项投放指标 + 状态 |
| 逐帧拆解 | 输出 | 时间轴/画面内容/画面元素/**文案字幕(ASR原文)**/音效/目的/可借鉴点 |
| 总结分析 | 输出 | Hook/人物/UI/特效/色彩/节奏/BGM/卖点 + 6维标签 + 受众/情绪/策略/优化 |
| 标签字典 | 参考 | 游戏名称/维度/标签值/说明/示例素材 |
| 效果聚合 | 输出 | 游戏/维度/标签值/素材数/平均花费/ROI/结论 |

### 6.3 飞书 Base（10 表，协作层）

素材主表 / AI分析结果 / 逐帧拆解 / 标签字典 / 效果聚合 / 游戏背景库 / AppsFlyer配置 / 素材映射 / 日效果 / 运行日志

### 6.4 NocoDB（历史，仅备份）

5 表 + 运行日志，不再作为新功能入口。

## 8. 游戏接入配置

```python
# analyze_pipeline_full.py GAME_CONFIG
GAME_CONFIG = {
    "心动防线": {"lang": "ja", "region": "日本"},
    "燃烧纪元": {"lang": "zh", "region": "港澳台"},
}
# OSS 前缀映射
PREFIX_MAP = {
    "心动防线": "心动防线-日/",
    "燃烧纪元": "燃烧纪元-投放素材/",
}
```

**接入新游戏 4 步**：
1. 导入投放 Excel（素材总览）
2. 写入 game_background（SQLite）
3. GAME_CONFIG + PREFIX_MAP 加一行
4. 跑 `analyze_pipeline_full.py --game 新游戏`

## 11. 已知问题与规避

| 问题 | 规避 |
|------|------|
| Mimo API 配额耗尽 (429) | 切 DeepSeek，.env 统一配置 |
| DeepSeek 推理模型输出被 reasoning 吃掉 | max_tokens ≥ 8000 |
| OCR 繁体中文乱码 | 用 Qwen2.5-VL 直读（规划） |
| 本地识别慢 (60~260s/条) | 申请 GPU 设备（RTX 4070 12GB） |
| 文件名/OSS 名不一致 | 指纹匹配（编号+日期+分辨率），已内置 |
| OSS 仅公司网络 | 内网/VPN 下运行 |
| 标签文本无 ID/别名 | 统一标签库（规划中） |
| 全量分析成本线性膨胀 | 触发式分析（规划中） |

## 12. 规划路线图

```
P0 (进行中)
  ├─ 标签准确性收尾: 证据链接进展示层 + 低置信度人工确认队列
  └─ 抽样复核机制 (准确率≥80% 验收)

P1
  ├─ 统一标签库: 统一ID + 层级 + 别名映射 + 版本化
  ├─ 素材↔标签多对多关联表 (带来源/置信度)
  ├─ 触发式分析: 消耗阈值/表现达标才全量拆解, 冷启动轻量拆解
  └─ Qwen2.5-VL 多模态升级 (提速2~3倍)

P2
  ├─ 变体生成工具接入 (逐帧拆解+ASR原文作输入)
  ├─ 效果聚合自动决策 (继续/观察/放弃)
  └─ 全量素材接入 (燃烧纪元 OSS 3000+)
```
